# 版本記錄

本專案版本號記在 `twalpha/__init__.py` 的 `__version__`。

---

## v0.1.0 — 2026-10-01

第一個可用版本。台股 7924 小資金策略回測與每日訊號工具，純 Python 標準庫實作。

### 環境需求

- Python 3.8 以上（macOS 內建的 `python3` 即可）
- **不需要** pip、pandas、numpy 或任何第三方套件

### 本版功能

**資料 (`datafeed.py`)**
- 證交所（上市）與櫃買中心（上櫃）日線抓取，會自動判斷標的掛在哪個市場
- 櫃買新舊兩種端點都試，官方改版時有備援
- 自行下載的 CSV 匯入：欄位名稱容錯（中英文皆可），民國日期自動轉西元
- 抓取結果合併寫入 `data/<股號>_daily.csv` 快取，官方 API 請求間隔 3.5 秒
- 離線用合成資料產生器，無網路也能驗證整套流程

**指標 (`indicators.py`)**
- SMA、EMA、RSI、ATR（Wilder 平滑）、MACD、布林通道、標準差、區間高低、斜率
- 每個指標在第 i 格只用第 i 格（含）以前的資料，單元測試有驗證無未來函數

**策略 (`strategies.py`)**
- `donchian` — N 日高突破 ＋ 量能放大 ＋ 長均線濾網（主力策略）
- `ma_cross` — 均線黃金交叉 ＋ 慢線翻揚
- `bb_squeeze` — 布林通道收斂後向上突破
- `macd` — 柱狀體翻正 ＋ 長均線之上
- `rsi_rev` — 長多格局中的短線超賣反彈
- `buyhold` — 買進持有基準線（不套停損、資金一次投入）
- 每個策略附參數網格，供最佳化使用

**回測引擎 (`engine.py`)**
- 逐根 K 棒事件式回測，訊號收盤後產生、隔日開盤成交並計滑價
- 跳空穿越停損時以開盤價成交；同一根 K 棒同時觸及停損與停利一律算停損
- 完整台股成本模型：手續費 0.1425%×折扣（含單筆最低收費）、賣出證交稅 0.3%
- 現金不足即無法進場，不允許隱形融資，並統計「資金不足錯過訊號」次數
- ATR 初始停損、ATR 移動停利、R 倍數停利、時間停損
- `size_position()` 為回測與實單共用的部位計算：
  `股數 = (資金 × 單筆風險%) ÷ (進場價 − 停損價)`，支援零股與整股

**績效 (`metrics.py`)**
- 總報酬、年化、最大回檔與最長回檔、Sharpe、Sortino、Calmar
- 勝率、賺賠比、獲利因子、每筆期望值（R 倍數與金額）、平均持有天數
- 交易成本總額、成本佔毛利比例、成本佔本金比例、資金在場比例
- 與同期同成本的買進持有基準線比較（超額報酬）

**最佳化 (`optimize.py`)**
- 參數網格搜尋，目標函數可選 calmar / sharpe / cagr / expectancy / profit
- Walk-forward 滾動驗證：訓練期找參數、測試期實測，串出樣本外權益曲線
- 測試期自動帶 200 根暖機資料，長天期指標不會因切窗失效

**報表 (`report.py`)**
- 終端機文字報告，附白話判讀（樣本太少、期望值為負、成本過重、回檔過大等警示）
- Markdown 報告、交易明細 CSV
- HTML 報告：含 SVG 權益曲線（策略 vs 買進持有）、hover 十字線與提示框、
  深色模式、統計磚、完整指標表、交易明細與月報酬表
- 交易成本結構表：各種單筆金額的來回成本與打平所需漲幅

**每日訊號 (`live.py`)**
- 最後一根 K 棒收盤後的訊號狀態、建議股數、估計進場價、停損價、
  單筆最大虧損、來回成本與打平所需漲幅

**命令列 (`cli.py`)**
- `fetch` / `costcheck` / `compare` / `backtest` / `optimize` / `walkforward` /
  `signal` / `demo` 八個子指令
- 資金、單筆風險%、零股整股、停損停利、券商折扣與最低手續費皆可由參數調整

### 測試

27 項單元測試全數通過（`python3 -m unittest discover -s tests`），涵蓋：

- 指標數值正確性，以及「竄改未來資料不會改變過去指標值」的無未來函數驗證
- 成交價必須等於次日開盤價加滑價
- 部位計算：單筆虧損受單筆風險%限制、整股模式整千進位、不會超出現金
- 成本模型：最低手續費門檻、單筆金額越大打平門檻越低、當沖稅減半
- 權益與交易損益一致、權益不為負、買進持有策略與基準線完全吻合
- 成本越高報酬越低、資料不足時明確報錯
- CSV 存讀往返、停牌資料列略過、民國日期轉換
- 網格搜尋排序與過濾、walk-forward 產生時間遞增不重疊的樣本外曲線

### 已知限制

- **本版的抓取功能尚未用真實 7924 資料驗證過。** 開發環境的網路政策阻擋
  `twse.com.tw`、`tpex.org.tw` 與 Yahoo Finance，所有回測數字皆來自合成資料，
  僅用於驗證引擎邏輯，不代表 7924 的任何實際績效。
  請在本機執行 `python3 -m twalpha fetch --stock 7924` 取得真實資料。
- 官方 API 若改版可能抓取失敗，此時請改用 `--csv` 匯入自行下載的日線檔。
- 僅支援單一標的、只做多、日線頻率；未處理除權息還原、停牌與漲跌停無法成交的情況。
- 回測假設可在隔日開盤以估計價格成交，實際流動性不足時會有落差。
