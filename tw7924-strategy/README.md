# 台股 7924 小資金策略研究專案 (twalpha)

一套**只用 Python 標準庫**寫成的台股策略回測與每日訊號工具。
macOS 內建的 `python3` 就能直接跑，不用 pip、不用 pandas、不用 numpy。

---

## 先說實話：沒有「最快賺錢」的策略

你問的是「小資金最快賺錢的策略」。我必須先講清楚三件事，否則後面的程式碼只會害你賠更快：

1. **追求「最快」等於追求「最大波動」。** 能讓 10 萬在三個月變 20 萬的做法，同樣能讓它變 5 萬。
   在回測裡，所有高年化報酬的參數組合，最大回檔幾乎都在 30% 以上。
2. **小資金的敵人不是行情，是成本。** 這是這個專案算給你看的第一張表
   （`python3 -m twalpha costcheck`，以手續費 6 折、單筆最低 20 元計）：

   | 單筆金額 | 來回總成本 | 要漲多少才打平 |
   |---:|---:|---:|
   | 3,000 | 49 元 | **1.83%** |
   | 5,000 | 55 元 | **1.30%** |
   | 10,000 | 70 元 | 0.90% |
   | 20,000 | 100 元 | 0.70% |
   | 50,000 | 236 元 | 0.67% |

   用 5,000 元做短線，你每一趟都要先贏 1.3% 才回到原點。一個月做 20 趟，等於先付掉 26% 的本金。
   **「小資金 + 高頻交易」在數學上就是必輸的組合**，跟你會不會看線無關。
3. **單一個股 + 單一策略 = 高度集中的賭注。** 7924 是中小型股，流動性與波動都和權值股不同，
   停損被跳空穿價、想買買不到的狀況會比你想像中多。

所以這個專案給你的不是「必勝策略」，而是一套**能誠實告訴你某個做法到底行不行的驗證工具**：
真實成本、隔日開盤成交、停損穿價保守估計、以及最重要的 **walk-forward 樣本外驗證**。

小資金真正能控制的只有三件事：**降低成本、控制單筆風險、只做勝算高的那幾次**。
這份工具就是照這三件事設計的。

## 快速開始（macOS / zsh）

```zsh
# 0. 確認 Python（macOS 內建即可，3.8 以上）
python3 -V

cd tw7924-strategy

# 1. 不用網路，先看完整流程長什麼樣（使用合成資料）
python3 -m twalpha demo

# 2. 看你的交易成本結構（換成你的券商折扣）
python3 -m twalpha costcheck --discount 0.28 --min-fee 1

# 3. 抓 7924 近五年日線（會自動判斷上市/上櫃，存成 data/7924_daily.csv）
python3 -m twalpha fetch --stock 7924 --years 5

# 4. 六種策略同條件較量
python3 -m twalpha compare --capital 100000 --lot odd

# 5. 回測單一策略並產生 HTML 報告
python3 -m twalpha backtest -s donchian --capital 100000 --html --csv-out
open output/7924_donchian.html

# 6. 最重要的一步：樣本外驗證（別跳過）
python3 -m twalpha walkforward -s donchian --train 500 --test 125

# 7. 今天該做什麼（含建議股數與停損價）
python3 -m twalpha signal -s donchian --capital 100000
```

> **抓不到資料怎麼辦？**
> 證交所／櫃買中心的 API 偶爾改版，公司網路或 VPN 也可能擋掉。
> 這時請自行下載日線 CSV（欄位含 `date, open, high, low, close, volume`，
> 中文欄名「日期, 開盤價, 最高價, 最低價, 收盤價, 成交股數」也讀得懂，民國日期會自動轉換），
> 然後用 `--csv 你的檔案.csv` 指定，例如：
> `python3 -m twalpha backtest -s donchian --csv ~/Downloads/7924.csv --html`

## 內建策略

| 名稱 | 邏輯 | 適合什麼行情 | 對小資金的意義 |
|---|---|---|---|
| `donchian` | 20 日高突破 ＋ 量能放大 ＋ 站上長均線 | 主升段、籌碼發動 | 交易次數少、單筆金額大，成本佔比低（**主力推薦**） |
| `ma_cross` | 均線黃金交叉 ＋ 慢線翻揚 | 中長波段 | 進出最少，最省手續費，但會晚進晚出 |
| `bb_squeeze` | 布林通道收斂後向上突破 | 盤整很久後的噴出 | 等待時間長，但進場點通常離停損很近（風險小） |
| `macd` | MACD 柱狀體翻正 ＋ 長均線之上 | 趨勢確立後跟進 | 訊號多，成本負擔中等 |
| `rsi_rev` | 長多格局中 RSI 超賣接刀 | 多頭回檔 | 交易頻繁，**小資金最容易被手續費吃掉的類型**，請看「成本佔毛利%」 |
| `buyhold` | 買進抱著不動 | — | 基準線。任何策略贏不過它，就不值得花時間盯盤 |

## 回測引擎刻意「對自己嚴格」的地方

回測最容易騙人的就是偷看未來。這裡的設計都是往保守方向做：

- **訊號在收盤後產生，隔日開盤成交**，並加上滑價（預設 0.1%，小型股建議調高）。
- **跳空低於停損時，用開盤價出場**，不是用停損價（真實世界你賣不到停損價）。
- **同一根 K 棒同時碰到停損與停利，一律算停損。**
- **真實台股成本**：手續費 0.1425%×折扣、單筆最低收費、賣出證交稅 0.3%。
- **現金不足就是買不到**，不會偷偷用融資；買不起的訊號會計入「資金不足錯過訊號」。
- 測試檔 `tests/test_twalpha.py` 有專門驗證「成交價必須等於次日開盤價」的案例。

## 風控與部位

```zsh
python3 -m twalpha backtest -s donchian \
  --capital 100000 \      # 期初資金
  --risk-pct 2 \          # 單筆最多虧掉總資金的 2%（= 2,000 元）
  --lot odd \             # 零股：小資金的關鍵，能精準控制部位大小
  --stop-atr 2 \          # 初始停損 = 進場價 - 2×ATR
  --trail-atr 3 \         # 移動停利 = 收盤 - 3×ATR
  --discount 0.28 --min-fee 1   # 你的券商條件
```

股數的算法是：`股數 = (資金 × 單筆風險%) ÷ (進場價 − 停損價)`，
再受限於現金、單一部位上限與零股／整股單位。這套邏輯**回測與實單（`signal` 指令）共用同一個函式**，
不會發生「回測一套、下單另一套」。

## 該看哪些數字

1. **每筆期望值 R**：平均一筆賺幾倍風險。**小於 0 就不要上線**，勝率再高都沒用。
2. **最大回檔 MDD**：你的本金與心臟撐不撐得住。MDD 40% 代表 10 萬會看到剩 6 萬。
3. **成本佔毛利%**：超過 30% 表示你在幫券商和國稅局打工，要降低交易頻率或提高單筆金額。
4. **超額報酬%**：贏不過 `buyhold` 的話，所有盯盤都是白工。
5. **walk-forward 的 OOS 年化**：這才是接近實戰的估計值，單段回測的漂亮數字通常是參數硬湊的。

## 小資金實務建議（從上面的成本結構推出來的）

- 單筆金額盡量 **≥ 20,000 元**，低於 10,000 元請直接放棄短線。
- 用**零股**控制部位，不要為了湊整張而放大風險。
- 找**電子下單折扣低、最低手續費 1 元**的券商，這一項就能省掉一半以上的成本。
- **不要當沖**：當沖省的是證交稅（0.3%→0.15%），但你付出的是最高的錯誤率與最高的交易頻率。
- 每天只花 5 分鐘：收盤後跑一次 `signal`，有訊號就在隔天開盤掛單，同時把停損掛好，然後關掉看盤軟體。

## 風險聲明

本專案是**程式與統計工具**，不是投資建議，也不保證任何獲利。
所有回測結果都是歷史資料的統計，過去績效不代表未來報酬；
實際下單還會遇到流動性不足、跌停賣不掉、除權息調整、公司重大事件等回測無法模擬的狀況。
請用你賠得起的錢，並自行承擔所有交易結果。
